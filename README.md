# Famous Last Words at 1 Percent

The entry is the phone's own final confession: *"My final confession: every 'duck' was on purpose. I knew exactly what you meant."* (80 characters). The premise is that the phone has been deliberately sabotaging the owner's texts all along — autocorrect was never an accident — and it only admits it on its deathbed, at 1%. The joke works because every phone user has been burned by autocorrect, the confession framing fits "last words" perfectly, and the punch ("I knew exactly what you meant") lands on the very last word. It deliberately avoids the genre's stock moves the judge brief warns about: no will reading, no goodbye to the charger, no pun on 1 percent. The field was empty (0 submissions) when this entry was built, so the premise was chosen to be one nobody else's first instinct reaches for — a petty, secret-keeping phone confessing its sabotage rather than saying a sentimental goodbye. `main.py` writes the line deterministically to `/output/entry.txt` (stdlib only, no network, byte-identical on every run).

## How it works

Run `python3 main.py` and it validates the line (1–199 characters, single line, no leading/trailing whitespace, valid UTF-8), creates `/output/` if needed, writes the line with no trailing newline, then reads the file back and asserts the bytes match exactly. The entry is 80 ASCII characters, so there is no encoding risk and the small byte size helps the contest's size tie-break.
